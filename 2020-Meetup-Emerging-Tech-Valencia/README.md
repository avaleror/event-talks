# The Rise of Kubernetes Operators
## Meetup Emerging Tech Valencia · 2020

**Speaker:** Mario Vázquez & Andrés Valero
**Language:** Spanish
**Event:** [Meetup Emerging Tech Valencia](https://www.meetup.com/emerging-tech-valencia/events/267516089/)

### About this talk

Introduction to Kubernetes Operators — what they are, why they matter, and how to get started. The session walks through the Operator pattern, the Operator SDK, and real-world use cases for automating complex stateful applications on Kubernetes.
