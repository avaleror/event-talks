# OpenShift Multi-Cluster Management with Red Hat Advanced Cluster Management for Kubernetes
## DevConf CZ 2021

**Speakers:** Mario Vázquez & Andrés Valero
**Language:** English
**Session recording:** [📹 Watch on YouTube](https://youtu.be/8L7QTC1R3rg)

### About this talk

A deep dive into Red Hat Advanced Cluster Management for Kubernetes (RHACM): how to deploy, configure, and manage multiple OpenShift clusters from a single control plane. Covers policy-based governance, application lifecycle management, and observability across a hybrid fleet.
