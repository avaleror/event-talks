# Edge, Are You Ready?
## SUSECON 2022

**Speakers:** Juan Herrera & Andrés Valero
**Language:** English
**Session recording:** [📹 Watch on YouTube](https://youtu.be/iJYcsg9BaBU)

### About this talk

A look at the state of Edge computing from a SUSE perspective — why Edge is different from traditional data centre workloads, what the key challenges are (connectivity, security, scale, lifecycle management), and how SUSE Edge addresses them. Includes live demos with K3s and Rancher on resource-constrained hardware.
