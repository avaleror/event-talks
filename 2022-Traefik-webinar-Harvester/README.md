# Build a Lightweight Private Cloud with Harvester, K3s, and Traefik
## Traefik Labs Webinar · 2022

**Speaker:** Andrés Valero
**Language:** English
**Event page:** [traefik.io](https://info.traefik.io/build-a-lightweight-private-cloud-with-harvester-k3s-traefik-proxy)
**Session recording:** [📹 Watch on YouTube](https://youtu.be/Lu60U2X7SYI)

### About this talk

How to build a fully functional private cloud using only open-source components: SUSE Harvester (HCI), K3s (lightweight Kubernetes), and Traefik Proxy. The session walks through the architecture, how the three components integrate, and a live demo from bare-metal VM provisioning through to application deployment behind Traefik.
