### About the talks

**OpenNebulaCon session:** How to deploy and manage Kubernetes clusters across multiple OpenNebula cloud regions. Covers the integration between OpenNebula and RKE2, storage with Longhorn, and the operational patterns for running production Kubernetes on top of OpenNebula infrastructure.

**Webinar:** Introduction to OneKE — the official Kubernetes engine for OpenNebula. What it is, how it differs from vanilla Kubernetes on OpenNebula, and how to get started.
